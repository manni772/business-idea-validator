# Business Idea Validator

An AI-powered business analysis tool that evaluates startup and business ideas using the Groq API (Llama 3.3). Built with vanilla HTML, CSS, and JavaScript — no frameworks or libraries.

## Live demo
[manni772.github.io/business-idea-validator](https://manni772.github.io/business-idea-validator)

Click **Load demo** to see a full analysis without an API key.

## Features
- Describes a business idea and receives a structured AI analysis across 8 sections
- Radar chart scoring across 5 dimensions: Market, Competitive Advantage, Feasibility, Revenue, Timing
- Competitor landscape cards with threat level ratings
- Idea history saved to localStorage — reload any previous analysis
- Side-by-side comparison of two saved analyses
- Email report and PDF export
- Demo mode — no API key required to see full output

## Tech stack
- Vanilla HTML, CSS, JavaScript (no frameworks)
- Groq API — llama-3.3-70b-versatile model
- Canvas API for radar chart
- localStorage for persistence

## How to use
1. Open the live link above
2. Click **Load demo** to see an example, or enter a Groq API key for live analysis
3. Describe your business idea and click Analyse
